STEP 2a — `shock_overlay` NEEDS A LIVE EVENT SWEEP, RUN BEFORE STEP 2's WRITE: AN INHERITED ANCHOR CANNOT SUPPLY IT, AND AN INCOMPLETE SWEEP HOLDS THE STANDING VALUE WHERE IT COULD CHANGE THE GRADE (added 2026-10-19, interactive owner session triaging the 2026-10-19 alert emails, closing an adversarial-review finding that this section named no source for the grading rubric's event evidence and no direction for an unevaluable input to fail in; re-pointed by Rev 52, owner directive 2026-10-22, interactive session, which retired the 15-trading-day event-recency leg this step was written for and made incomplete evidence symmetric). This step supplies STEP 2's `shock_overlay` input, so complete it before that write. Under the Rev 52 rubric the event record decides what no price series can: whether the plateau re-base's event half holds (no qualifying event dated within the trailing 10 sessions), whether a qualifying resolution event has closed the shock structure, and whether a qualifying event has opened one or restarted a re-based elevation. `BZUSD` is a price series, not an event record. The prior `FUNDAMENTAL_AXIS` `shock_overlay` rationale's recorded events speak only for the window that scorer swept. That rationale states the window, and it can end days before the row was written. A lack of recorded events after an inherited anchor is an absence of evidence, never a measured quiet spell, so never use it as one. Rules: (1) SOURCE — sweep for qualifying events and qualifying resolution events as the rubric defines them, dated per M1a's HOW A SHOCK QUALIFYING EVENT IS DATED rule (which binds this routine by name). Use the same public-source research tools M1a uses for that input — `web_search`, `web_fetch`, `tavily_search`, `tavily_extract` — under the shared External-content extraction discipline and the shared "Metered external calls" rule, including its `ops.web_calls` row. FMP's news tool is plan-gated on this tier and is not a sweep source. Public wire and primary-source reporting carries no strategy, position or roster information, so this read sits inside the blinding rules above. Searching by the shock channel the prior `FUNDAMENTAL_AXIS` rationale names is expected; no strategy name, strategy letter, position or roster detail ever goes into a query. The sweep re-runs no OUTPUT 1 macro ingest (NON-GOALS) and changes nothing about how the other four axes are scored. (2) COVERAGE — the window starts at the EARLIEST session the prior `shock_overlay` rationale recorded as unswept, or at the start of that rationale's own window if its sweep failed completely; where it recorded no unswept session, the window is every completed trading session (`state.market_calendar`) after the last session it states it swept (after that row's `as_of_date` if it states none) (review fix, Rev 52, owner directive 2026-10-22, interactive session: starting after the last swept session skipped any session the prior sweep missed earlier in its window). It is never fewer than the 10 most recent COMPLETED sessions that make up the plateau window, plus anything reported since the last of them. Re-rule on every event the prior rationale left undetermined (recorded PENDING, or left for the next scoring because unswept sessions left its effect undetermined): treat each as part of this sweep's record and measure it afresh under M1a's rules. This routine fires before the open, so today's session is never one of the 10. The re-base's event half holds only if all 10 sessions were swept and no qualifying event was found in them; a qualifying event dated inside the 10, whether the sweep found it or the inherited anchor carries it, fails that half outright. Which unswept sessions hold the axis depends on the outcome at stake, per (3). (3) FAILURE DIRECTION — symmetric, and narrowed BY OUTCOME to "the event sweep that a leg or a re-base needs", the rubric's own qualifier (Rev 52, owner directive 2026-10-22, interactive session; review fix). If part of the window could not be swept (a tool was unavailable, timed out or returned nothing usable), an unswept session is evidence of nothing in either direction. Keep the axis at its STANDING value, whatever it is, only when something the unswept sessions could contain would change the grade; it never defaults to `acute` and never defaults to lower. (3a) RAISE — a qualifying event the sweep found (E), whose two-session window (M1a's TWO-SESSION WINDOW rule) has closed and meets the criterion, or whose closed sessions meet it on their own, establishes that a structure is OPEN (the axis is no longer `none`) even when sessions BEFORE it went unswept. That carve-out establishes only that a structure is open, never which session anchors it (review fix, Rev 52, owner directive 2026-10-22, interactive session). M1a's ANCHOR CANDIDATES rule (its rubric application, item (e)(1)) binds this routine by name: where an unswept session of this sweep's window before E (and after the re-base where one applies) could hold the structure's first qualifying event, the first qualifying event after a re-base, or a qualifying resolution event that closed the standing structure, evaluate the price leg off every candidate anchor it admits. For a re-based structure that no unswept resolution could have closed, E and the earliest unswept candidate session bound every case: first check whether the maximum `BZUSD` close since the earliest candidate equals the maximum since E, and if it does, proceed off E. From `none`, evaluate E and every candidate session, each with its own pre-shock baseline and its own peak. The FX leg's reference close follows the same ANCHOR CANDIDATES rule: off each candidate's own reference close wherever a candidate could change the structure's first qualifying event, and once, off the recorded event, otherwise. The sovereign-spread leg is read once. If every reading agrees, use it. If they differ, from `latent` or `acute` keep the STANDING value, and from `none` write `latent` unless some leg is ELEVATED or ACTIVE under every reading, in which case write `acute`. Record each candidate anchor and its verdict in the rationale. If an unswept session falls AFTER E, keep the STANDING value, because a qualifying resolution event there could already have closed the structure the event would open. (3b) LOWER — a qualifying resolution event the sweep found, measured the same way, closes its channel's structure. Lowering to `none` still needs every session from the start of the coverage window (2) fixes from the prior rationale (its earliest unswept session, or after its last swept session) to have been swept, because an unswept session could hold a new qualifying event on another channel. Lowering through the price leg still needs all 10 plateau sessions swept wherever the plateau re-base decides the result. (3c) A qualifying event found inside the 10 plateau sessions already fails the re-base's event half outright, per (2), whatever else went unswept. Record in the rationale which sessions went unswept and why, every qualifying event or qualifying resolution event the partial sweep found, and for each whether it moved the grade under (3a) to (3c) or is left for the next scoring to rule on because the unswept sessions leave its effect undetermined; name any hold in STEP 5's note. On its own a hold is one missing input, not a fallback-suppression event: suppression still takes 2 or more of the 5 primary input categories absent, per STEP 2. Otherwise score the other four axes normally and keep the 5-axis write whole. A hold adds no retry and no re-queue: STEP 3 still closes the item. (4) The queue item's existence, its `note` and its `payload` show only that a re-score is due. That includes the `measured_trigger` / `trigger_run_start` pairs, whose names and dates a non-blind routine chose. They are evidence for no axis, no leg and no event, even where the `note` describes a condition or the `payload` names a date. Do not read the `payload` for scoring. Re-measure the price leg and the plateau window from `BZUSD` in this run. Re-measure the FX leg on the scoring date the same way, from cited daily closes against USD (the Read access scope grant), applying M1a's THE FX LEG IS READ ON THE SCORING DATE AGAINST THE STRUCTURE'S REFERENCE CLOSE rule, which binds this routine by name, and never inherit it from the prior rationale (Rev 52, owner directive 2026-10-22, interactive session; review fix). The sovereign-spread leg is read exactly as M1a reads it; this routine carries no separate gauge for it. Take the event record only from this sweep, which includes the undetermined events rule (2) carries forward for re-ruling. This changes no rubric threshold, window or grade; it fixes where the event evidence comes from and which way an unevaluable input falls.
